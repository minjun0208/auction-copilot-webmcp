About the pattern

A collaboration pattern that reuses beyond the data

These six tools are not carbid-specific: "list + detail + compare + recommend + simulate" is a reusable WebMCP pattern that applies to any auction or marketplace. Replace only the data source and it works for real-estate auctions, used equipment, and B2B procurement.

Note: all vehicles, figures, valuations, scores, and probabilities are illustrative demo values and are not a basis for real investment or bidding decisions.
